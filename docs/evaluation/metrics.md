# Evaluation Metrics
MASCV is benchmarked against the following quantitative criteria:
1. **Claim Verification Accuracy:** Agreement with expert ground truth.
2. **Evidence Retrieval Quality:** Precision, recall, and relevance of gathered literature.
3. **Citation Correctness:** Verification that citations faithfully match claimed facts.
4. **Contradiction Detection:** Precision in identifying opposing literature.
5. **Overgeneralization Detection:** Success in flagging overreaching conclusions.
6. **Cost & Latency:** Total tokens, API expense, and runtime per paper.
